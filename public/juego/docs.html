1. Introduction

Welcome to the Pop Candy game documentation! This document provides a comprehensive guide to understanding and customizing the Pop Candy game. Whether you want to change the game's appearance, adjust gameplay mechanics, or modify sounds, this guide has you covered.

Pop Candy is a match-3 style HTML5 game where players match candies on a game board to score points. The game features colorful candy graphics, a timer system, and engaging sound effects to create an addictive gaming experience.

Note: No programming knowledge is required for basic customization. For more advanced changes, a basic understanding of HTML, CSS, and JavaScript may be helpful, but this guide will walk you through step by step.

3. Game Mechanics

Before customizing, it's important to understand the core game mechanics:

Game Board

The game uses an 8×8 grid of candies. Each position on the grid contains a candy of a specific type (star, heart, circle, etc.).

Matching Mechanism

Players can swap adjacent candies to create matches of 3 or more identical candies in a row or column. When a match is made:

  • The matched candies are removed from the board
  • New candies fall from the top to fill empty spaces
  • Points are awarded based on the number of candies matched
  • Time is added to the timer (by default, 2 seconds per candy matched)

Timer System

The game includes a timer that constantly ticks down. Initially set to 60 seconds, the timer decreases at a rate of 0.4 seconds per real second. Matches add time back to the timer. When the timer reaches zero, the game ends.

Hint System

If a player is inactive for 5 seconds, the game highlights a possible match with animation. If no valid moves exist, the board is automatically shuffled.

Score System

Players earn points for making matches. The game tracks both the current score and the best score (stored in the browser's local storage).

Game States

The game has several states:

  • Welcome Screen - Initial screen with the game title and play button
  • Playing - Active gameplay
  • Paused - Game is temporarily paused
  • Game Over - Timer has run out, showing final score

4.1 Visual Customization

Changing Game Colors

The game uses CSS variables for easy color customization. Open css/styles.css and find the :root section at the top:

:root {
    --primary: #ff7eb3;
    --primary-dark: #e7649a;
    --secondary: #b088ff;
    --text-color: #333333;
    --board-bg: rgba(255, 255, 255, 0.7);
    --board-border: #ffb8de;
    --cell-size: clamp(35px, 9vw, 55px);
}

To change colors, simply modify these hex color codes. For example, to change the primary color from pink to blue, you would change #ff7eb3 to #7eb3ff.

Changing Game Background

To replace the game background:

  1. Add your new background image to the assets/ folder
  2. Modify the background style in css/styles.css. Find the body selector and update it:
body {
    background-image: url('../assets/your-background.png');
    background-size: cover;
    background-position: center;
    /* Adjust these properties as needed */

4.2 Gameplay Customization

Changing Game Difficulty

Several parameters in js/game.js control the game difficulty:

Parameter Default Value Effect
this.maxTime 60 Starting time in seconds
this.timeDecreaseRate 0.4 How quickly time decreases (higher = faster/harder)
this.timeIncreasePerMatch 2 Seconds added per candy matched
this.hintDelay 5000 Milliseconds of inactivity before showing a hint
this.boardSize 8 Size of the game board (8×8)

To make the game easier, you could:

  • Increase this.maxTime (e.g., to 90 for more starting time)
  • Decrease this.timeDecreaseRate (e.g., to 0.3 for slower time decrease)
  • Increase this.timeIncreasePerMatch (e.g., to 3 for more time reward)

To make the game harder, do the opposite.

Changing Board Size

To change the board size:

  1. In js/game.js, change this.boardSize = 8; to your desired size
  2. In css/styles.css, update the .game-board CSS to match: 
    .game-board {
    display: grid;
    grid-template-columns: repeat(8, var(--cell-size)); /* Change this number */
    grid-template-rows: repeat(8, var(--cell-size)); /* Change this number */
    ...
}

Warning: Changing the board size may require additional adjustments to maintain game balance and screen layout.

Modifying Score System

The scoring logic is in the checkAndRemoveMatches function in js/game.js. By default, players earn 10 points per matched candy. To change this, find and modify:

// Calculate score (10 points per candy)
const matchScore = matches.length * 10;
this.score += matchScore;

6. Performance Optimization

Canvas Rendering

For better performance, especially on mobile devices, you can convert the game board to use Canvas instead of DOM elements. This requires more advanced JavaScript modifications:

  1. Create a createCanvasBoard method in js/game.js:
createCanvasBoard() {
    // Create canvas element
    const canvas = document.createElement('canvas');
    canvas.width = this.boardSize * 60; // Adjust size as needed
    canvas.height = this.boardSize * 60;
    canvas.id = 'gameCanvas';
    
    // Replace board with canvas
    this.gameBoard.parentNode.replaceChild(canvas, this.gameBoard);
    this.gameBoard = canvas;
    this.ctx = canvas.getContext('2d');
    
    // Load candy images
    this.candyImages = {};
    const imageLoadPromises = this.candyTypes.map(candy => {
        return new Promise(resolve => {
            const img = new Image();
            img.onload = () => resolve();
            img.src = candy.image;
            this.candyImages[candy.type] = img;
        });
    });
    
    // Continue initialization after images load
    Promise.all(imageLoadPromises).then(() => {
        this.fillCanvasBoard();
        this.setupCanvasEvents();
    });
}
  1. Add a method to render the board:
renderCanvasBoard() {
    // Clear canvas
    this.ctx.clearRect(0, 0, this.gameBoard.width, this.gameBoard.height);
    
    // Draw each candy
    const tileSize = this.gameBoard.width / this.boardSize;
    
    for (let i = 0; i < this.boardSize; i++) {
        for (let j = 0; j < this.boardSize; j++) {
            const candy = this.board[i][j];
            if (candy.type) {
                const img = this.candyImages[candy.type];
                
                // Draw candy image
                this.ctx.drawImage(
                    img, 
                    j * tileSize, 
                    i * tileSize,
                    tileSize,
                    tileSize
                );
                
                // Draw selection/animation state if needed
                if (candy.isSelected) {
                    this.ctx.strokeStyle = '#FFFFFF';
                    this.ctx.lineWidth = 3;
                    this.ctx.strokeRect(
                        j * tileSize + 3,
                        i * tileSize + 3,
                        tileSize - 6,
                        tileSize - 6
                    );
                }
            }
        }
    }
}

Then you would need to modify the game's event handlers and update loop to work with canvas instead of DOM elements. This is an advanced modification that requires good JavaScript knowledge.

Asset Preloading

Improve load times by preloading assets. Add this method to the CandyGame class in js/game.js:

preloadAssets() {
    return new Promise(resolve => {
        const assets = [];
        
        // Add all candy images
        this.candyTypes.forEach(candy => {
            assets.push(candy.image);
        });
        
        // Add audio files
        const audioFiles = [
            'assets/audio/background-music.mp3',
            'assets/audio/match.mp3',
            'assets/audio/swap.mp3',
            'assets/audio/invalid.mp3',
            'assets/audio/game-over.mp3',
            'assets/audio/hint.mp3'
        ];
        
        assets.push(...audioFiles);
        
        // Track loading progress
        let loaded = 0;
        
        assets.forEach(asset => {
            if (asset.endsWith('.mp3') || 
                asset.endsWith('.wav') || 
                asset.endsWith('.ogg')) {
                // Preload audio
                const audio = new Audio();
                audio.addEventListener('canplaythrough', () => {
                    loaded++;
                    if (loaded === assets.length) resolve();
                }, { once: true });
                audio.src = asset;
            } else {
                // Preload image
                const img = new Image();
                img.addEventListener('load', () => {
                    loaded++;
                    if (loaded === assets.length) resolve();
                }, { once: true });
                img.src = asset;
            }
        });
    });
}

Call this method during game initialization and show a loading screen until assets are loaded.

8. Browser Compatibility

Adding Polyfills

For older browsers, you can add polyfills to ensure compatibility. Create a new file called js/polyfills.js with the following content:

// Polyfills for older browsers
if (!Array.from) {
    Array.from = function(iterable) {
        return [].slice.call(iterable);
    };
}

if (!Element.prototype.closest) {
    Element.prototype.closest = function(selector) {
        let el = this;
        while (el) {
            if (el.matches(selector)) {
                return el;
            }
            el = el.parentElement;
        }
        return null;
    };
}

if (!Element.prototype.matches) {
    Element.prototype.matches = Element.prototype.msMatchesSelector || 
                               Element.prototype.webkitMatchesSelector;
}

Then include this file in index.html before your other scripts:

<script src="js/polyfills.js"></script>
<script type="module" src="js/game.js"></script>

9. Troubleshooting

Game Won't Start

  • Problem: Clicking the play button doesn't start the game.
  • Solution: Check the browser console for errors. This might indicate missing files or JavaScript errors.

No Sound Playing

  • Problem: Game sounds or music aren't playing.
  • Solution:
    • Verify sound is enabled in the game (check the sound button)
    • Check that audio files exist in the correct location
    • Some browsers require user interaction before playing audio - click somewhere on the page first

Game Performance Issues

  • Problem: Game runs slowly or animations stutter.
  • Solution:
    • Reduce the size/complexity of candy images
    • Simplify CSS animations
    • Consider reducing the board size for slower devices

Candies Don't Match Properly

  • Problem: Matching candies doesn't remove them or add score.
  • Solution: Check for JavaScript errors in the console. If you've modified the matching logic, verify that your changes are consistent with the game mechanics.

Custom Images Don't Appear

  • Problem: After replacing candy images, they don't show up.
  • Solution:
    • Verify file paths and names are correct
    • Check image formats (PNG recommended)
    • Clear browser cache (Ctrl+F5 or Cmd+Shift+R)

Audio Not Playing in Mobile Browsers

  • Problem: Audio doesn't play on mobile devices, particularly on iOS.
  • Solution: Mobile browsers require user interaction before playing audio. Add this code to js/audio.js: 
    initAudio() {
    // Flag to track if audio has been initialized
    this.audioInitialized = false;
    
    // Add a one-time listener for user interaction
    const unlockAudio = () => {
        if (!this.audioInitialized) {
            // Create and play a silent sound
            const audio = new Audio();
            audio.play().catch(() => {});
            
            this.audioInitialized = true;
            
            // Now initialize the real audio
            if (this.isMusicEnabled) {
                this.playMusic();
            }
        }
        
        // Remove event listeners
        document.removeEventListener('click', unlockAudio);
        document.removeEventListener('touchstart', unlockAudio);
    };
    
    document.addEventListener('click', unlockAudio);
    document.addEventListener('touchstart', unlockAudio);
}
